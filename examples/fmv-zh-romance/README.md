# Ví dụ Mẫu 1: Game FMV Tình Cảm Đô Thị Trung Quốc
*Phong cách: Tương tự "Love Is All Around" (完蛋！我被美女包围了！)*

## Điểm Nổi Bật Về Bản Dịch:
1. **Triệt hạ hoàn toàn "Tôi - Bạn"**: Nam chính là cấp dưới kém tuổi, xưng *em - sếp Triệu / chị*, Triệu Mẫn là sếp nữ sắc sảo, xưng *tôi - cậu*.
2. **Khẩu ngữ trẻ trung**: Dùng trợ từ tự nhiên (`ngẩn người gì đấy?`, `khéo chọn ghê`, `xử cậu thế nào`).
3. **Nút bấm QTE ngắn gọn**: Dưới 18 ký tự, dứt khoát (*"Hứa hoàn thành nhiệm vụ"*, *"Tiếp tục trêu chọc sếp"*).
4. **CPS tối ưu**: Trung bình 14.8 CPS, người chơi đọc thoải mái và ngắm trọn vẹn nụ cười duyên của nữ diễn viên.
