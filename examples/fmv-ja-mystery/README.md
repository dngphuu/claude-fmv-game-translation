# Ví dụ Mẫu 2: Game FMV Trinh Thám Nhật Bản
*Phong cách: Tương tự "Death Come True" / "428: Shibuya Scramble"*

## Điểm Nổi Bật Về Bản Dịch:
1. **Khắc họa vai trò ngôn ngữ (Yakuwarigo)**: Makoto dùng `おい、起きろ!` với giọng gắt gỏng, chuyển ngữ thành *"Này, tỉnh lại đi!"*.
2. **Khẩu ngữ sinh động**: *"Đầu tôi đau như búa bổ"* thay vì dịch máy thô cứng *"Đầu tôi đau như nứt ra"*.
3. **Giữ nguyên thẻ tiếng WebVTT**: `<v Makoto>`, `<v Karaki>` được bảo toàn nguyên vẹn.
4. **Nút bấm phản xạ nhanh (QTE)**: Dưới 15 ký tự (*"Gọi báo cảnh sát"*, *"Tháo chạy khỏi hiện trường"*).
